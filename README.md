# Court Docket Pocket DisArm App
Problem Statement

When users search varius search engines, official court docket records do not appear in the initial query because the standard search database does not have a live, real-time connection to active official court terminals. As a result, 3rd party firms create misinformation when users search for updated information used to make critical decisions about others lives that may not be accurate without a way to gather accurate information in one step.

The Solution

The Federal Judiciary hosts active dockets behind the PACER login paywall. Public search engines can only index documents when third-party legal platforms purchase, download, and publish them to the open web. Our app bypasses the need for third parties need to purchase, download, and publish to the open web where there is room for critical error and misinformation in the purchase, download, and publishing actions without recourse, before our app's solution. Our app supports the US Court of Administration's need to maintain control of it's dockets, even through private search engine user searches without misinformation.
